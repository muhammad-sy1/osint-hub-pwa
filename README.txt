1) ارفع كل الملفات (مع مجلد fonts) في مستودع GitHub جديد (public).
2) Settings > Pages > Branch: main / root > Save.
3) افتح https://USERNAME.github.io/REPO/ وتأكد إن الصفحة تشتغل.
4) pwabuilder.com > الصق الرابط > Package for stores > Android > Download.
5) ثبّت ملف .apk، واحتفظ بملف signing.keystore.
